# Revision History

A record of significant changes to the Replicant GEN 1 build documentation, BOM, and hardware specifications.

---

## 2026-04-03

### Parts List (BOM) — Fastener corrections

**Heatset inserts**
- Qty increased from **4 → 10** to reflect actual build requirement.

**Delta PT® arm-boss screws — stack-variant split**
- **30×30 FC stack:** use **M3×16** CSK Torx (×4) — previously unlisted.
- **20×20 FC stack:** use **M3×25** CSK Torx (×4) — previously listed without stack callout.

**ISO 7380 Button Head — nose cone**
- Changed from M3×12 (×4) → **M3×10 (×4)** to match actual hardware.

**ISO 7380 Button Head — front top plate arm mounts**
- Added **M3×12 (×4)** — previously unlisted.

**ISO 7380 Button Head — spine**
- Split former combined spine entry into:
  - **Titanium M3×14 (×2)** — forward spine
  - **Steel M3×16 (×1)** — rear spine standoff

**ISO 14580 Low Head Torx — stack-variant split**
- **20×20 FC stack:** spine + bottom arm mounts use **M3×25 (×5)** — unchanged spec, now clearly callout.
- **30×30 FC stack:** same callouts use **M3×35 (×6)** low head — longer to clear taller stack.

**ISO 7380 M3×35 — removed**
- The M3×35 fastener is a **low-head**, not a button head. Moved to the ISO 14580 Low Head section and removed from the button head table.

**Build checklist widget**
- Added **FC stack** toggle (20×20 / 30×30) — checklist now filters stack-specific fasteners per selection.

---

*Changes marked with a stack variant (20×20 / 30×30) only apply to that specific FC stack configuration.*
