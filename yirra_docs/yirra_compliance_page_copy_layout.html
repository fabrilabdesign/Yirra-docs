Open-source route
Free · self-managed compliance

Your ongoing obligations every time you distribute or sell:

  • 1Publish all source files — schematics, PCB layouts, BOM, firmware, and assembly docs
  • 2Include the full CERN-OHL-W-2.0 licence text with every distribution
  • 3Prepare a Notices file documenting every modification to the original design
  • 4Retain all existing copyright and attribution notices from the source files
  • 5Mark every modified file with the date, nature, and author of the change
  • 6Provide durable source file access for at least 3 years after last sale
  • 7Ensure all downstream recipients can exercise the same licence rights
  • 8Maintain records sufficient to demonstrate compliance if requested
  • 9Respond to licence questions from any recipient who contacts you
Battery price: AUD $229 / unit · No support · No design file updates
